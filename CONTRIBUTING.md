# Contributing to HookLab

Use Node 24.14 or newer. Run `npm ci`, `npx playwright install chromium`, `npm test`, `npm run build` and `npm run format:check` before opening a pull request.

Report a reproducible example, expected behavior, actual behavior and environment. Use synthetic data. Add regression coverage for a meaningful bug. Discuss large changes in an issue first. Keep interfaces keyboard accessible and test narrow screens.

AI-assisted contributions are welcome when you understand, review and test the result. Describe relevant limitations honestly.
